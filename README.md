# 関西 インターネット通信 × 電気代 コスパ最強コンビ比較シミュレーター

関西エリア（大阪・京都・兵庫・滋賀・奈良・和歌山）における主要な光回線5社と電力会社6社（全30通りの組み合わせ）から、スマホセット割・電気ガスセット割・初年度割引・キャッシュバックを加味して実質負担が最も安い組み合わせを自動算出するWebアプリケーションです。

## 特徴
- **光回線5社 × 電力会社6社（全30通り）をリアルタイム比較**
  - 光回線：eo光 / NURO光 / GMOとくとくBB光 / ドコモ光 / ソフトバンク光
  - 電力会社：関西電力 / eo電気 / 大阪ガスの電気 / シン・エナジー / オクトパスエナジー / おうちでんき（ソフトバンクでんき）
- **必須オプション費用の自動差し引きと公式情報ソースリンク**
  - スマホセット割適用に必要なオプション料金（NURO光でんわ等）を差し引いた実質割引額で計算し、すべての割引条件に公式情報ソースURLへのリンクを掲載。
- **コスパ順ベスト10ランキング ＆ 全30パターン積み上げ横棒グラフ**
