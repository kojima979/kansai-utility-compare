# 関西 インターネット通信 × 電気代 コスパ最強コンビ比較シミュレーター

関西エリア（大阪・京都・兵庫・滋賀・奈良・和歌山）における主要な光回線5社と電力会社8社（全40通りの組み合わせ）から、スマホセット割・電気ガスセット割・初年度割引・キャッシュバック・公式ポイント還元（dポイント・Ponta・はぴe等）を加味して実質負担が最も安い組み合わせを自動算出するWebアプリケーションです。

## 特徴
- **光回線5社 × 電力会社8社（全40通り）をリアルタイム比較**
  - 光回線：eo光 / NURO光 / GMOとくとくBB光 / ドコモ光 / ソフトバンク光
  - 電力会社：関西電力 / eo電気 / 大阪ガスの電気 / シン・エナジー / オクトパスエナジー / おうちでんき（ソフトバンクでんき） / ドコモでんき / auでんき
- **公式ポイント制度の考慮とON/OFF切り替え**
  - dポイント（ドコモ光・ドコモでんき）、Pontaポイント（auでんき）、はぴeポイント（関西電力）、eoポイント（eoプレミアムクラブ）等の公式ポイント還元を1pt＝1円換算で算出（考慮有無をフォームで切り替え可能）。
- **必須オプション費用の自動差し引きと公式情報ソースリンク**
  - スマホセット割適用に必要なオプション料金（NURO光でんわ等）を差し引いた実質割引額で計算し、すべての割引・ポイント条件に公式情報ソースURLへのリンクを掲載。
- **コスパ順ベスト10ランキング ＆ 全40パターン積み上げ横棒グラフ**
